# Windows 灯控后台版

基于上游 ENE 6K7750 协议的 Windows 后台实现，在铭瑄 MS-Terminator B760M D4（USB `0CF2:7750`，接口 `MI_00`）上测试。程序使用 WinUSB，仅控制灯光分组 0、1，不操作风扇 PWM。其他主板和控制器未经验证；检测到的灯光分组不匹配时不会写入。

默认每 90 秒循环一次颜色，固定亮度 75%，没有呼吸效果或操作界面。Windows 用户登录 30 秒后由计划任务启动。控制器断开后会重试连接；睡眠恢复和实际重新登录后的启动尚未验证。与其他灯控程序同时使用可能产生冲突。

## 构建和运行

需要 Windows x64、.NET Framework 4.x、系统自带的 WinUSB 驱动，以及兼容的控制器。请先确认目标接口已绑定 WinUSB；本项目不会自动更换驱动。

1. 双击 `重新编译.cmd`，在本目录生成 `MaxsunRGBBackground.exe`。
2. 双击 `安装并启动.cmd`，建立当前用户的登录计划任务并启动后台程序。目录路径应保持不变。
3. 双击 `停止并取消自启.cmd` 可停止程序并移除该任务。

源码和构建脚本不包含预编译程序。首次写入前会将 LED RAM 备份到本地 `backups/`；这不保证能够恢复原厂动态模式。日志及备份不会提交。程序未经代码签名。

## 代码和许可

`Background.cs` 负责色彩循环，`EneDevice.cs` 负责 WinUSB 通信，`Probe.cs` 包含诊断和备份代码。调试写入命令会改变灯效。代码基于上游项目的 MIT 许可，详见 `LICENSE`。
